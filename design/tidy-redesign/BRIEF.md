# Tidy 自适应改版 — 设计简报

## 问题

现版「报纸多栏账本风」在窗口变窄时错乱（见用户截图）：

- 头条用固定的超大衬线字号（约 64–72px），800px 宽时断成 4 行，字被挤得很碎。
- 装饰用的期号大数字「1」绝对定位，窄窗口下压在正文和编者按上。
- 按钮「开始扫描 →」文字换行成两行。
- 三栏布局用固定宽度（左栏 330px、右栏 250px），中间栏被挤到约 200px，账目行叠字。

窗口尺寸：默认 1320×720，最小 800×560（`desktop/src-tauri/tauri.conf.json`）。
所有设计在 **1320 和 800 两个宽度** 都必须整齐。

## 不变的品牌基因（两个方案共用）

来自 `desktop/ui/src/styles/tokens.css`：

- 纸色 `--paper #faf8f3`，墨色 `--ink #26241f`，次墨 `#6d675a`，淡墨 `#8a8578`，幽灵墨 `#c4bcaa`
- 唯一强调色锈红 `--rust #a4432c`（深 `#7e3020`）。可点击的东西才用锈红。
- 栏线：粗 `#26241f`，细 `#d8d2c3`，点线引导 `#b5ae9e`
- 底色块 `#efe9dc / #e8ddce / #e0d5c2 / #d9c1ac / #c08468`
- 状态色：moss `#4e6b4a`、ochre `#9a6a1f`、rust
- 字体：衬线 `"Noto Serif SC", "Songti SC", serif`；等宽 `"IBM Plex Mono", "SF Mono", ui-monospace, monospace`；界面 `-apple-system, "PingFang SC", system-ui, sans-serif`
  （设计稿用 Google Fonts 加载 Noto Serif SC 400/600/700 与 IBM Plex Mono 400/500）
- 直角为主。只有窗口外壳和小标签有圆角。
- 报头：`TIDY` 衬线字母间距大、栏目 Tab「清理 软件 优化 分析 状态」、右侧日期行；下方双线（粗 2.5px + 细 1px）。

## 自适应硬规则（两个方案都必须遵守）

1. **字号全部流体化**：大字用 `clamp(最小, 视口相关, 最大)`。头条在 800 宽时最多 2–3 行，不能一行只有两三个字。
2. **栏宽不用固定像素**：用 `grid-template-columns: minmax(0, 1fr) minmax(240px, 300px)` 之类；低于断点（约 980px）时右栏移到下方，变成横向一排。
3. **按钮、Tab、数字、日期不换行**：`white-space: nowrap; flex: none`。只有正文段落可以换行。
4. **没有压字的装饰**：装饰元素必须在自己的格子里，或在窄宽度下隐藏。
5. **行内对齐**：标签 + 点线引导 + 数值的行，标签可截断（省略号），数值永不收缩。
6. **报头**：800 宽时 Tab 仍在一行；日期行可缩短（只留时间）或隐藏。
7. 中文正文行高 1.7 以上；`text-wrap: pretty`；标题 `text-wrap: balance`。
8. 不用媒体查询以外的 JS 做布局。断点用 `@media (max-width: …)`，这样在应用里也能直接用（应用窗口 = 视口）。

## 方案 A · 「宽幅报纸 · 流体版」

保留现在的版式，只修自适应。像同一份报纸的不同开本。

- 结构和现版一致：期号眉题 → 大衬线头条 → 署名线 → 框线按钮；右侧「编者按」（首字下沉）+ 统计账目。
- 头条 `clamp(36px, 3.6vw + 10px, 64px)`，行高 1.15，`text-wrap: balance`。
- 期号大数字改为：放在头条左侧的独立窄栏里（像报纸版号），≤980px 时隐藏。不再绝对定位压字。
- ≤980px：单栏。编者按变成头条下方的一段引文；三个统计变成一行三格（上次清理 / 当期回收 / 累计已省）。
- 账目预览：左栏总额 + 中栏账目 + 右栏说明。≤1100px 右栏说明并到左栏底部；≤980px 总额变成顶部一行横幅（数字 + 单位 + 按钮），账目占满宽度。
- 其他页（软件、优化、分析、状态）沿用同样的栏格逻辑。

## 方案 B · 「小报 · 模块栏格」

报纸味从「巨大字号」转到「版面结构」。像小报头版：很多带框线的模块，按网格自动排。天生稳定。

- 报头紧凑一行：`TIDY` + 栏目 Tab 带版号（`A1 清理`、`B1 软件`、`C1 优化`、`D1 分析`、`E1 状态`，版号用等宽小字）+ 右侧时间。
- 头条字号上限低：`clamp(26px, 1.6vw + 14px, 40px)`。把视觉重量交给 **数字**：关键数字用衬线大号数字放在框线「数据栏」里。
- 主体用模块网格：`grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))`，模块之间用 1px 栏线分隔（不是卡片阴影）。每个模块有小眉题（等宽、字母间距）+ 内容。
- 顶部有一条全宽「行情带」：一排关键指标，用竖线分隔，窄宽度时自动换成两行。
- 主按钮是实心锈红长条按钮（白字），不是双框线。
- 列表（账目、软件列表、进程表）用紧凑表格：等宽数字右对齐、点线行分隔、斑马底色可选。
- ≤980px 时模块自然变成 1–2 列，不需要专门改结构。

## 页面清单（每个方案都做）

| 文件 | 页面 |
|---|---|
| `clean-home.html` | 清理 · 首页（未扫描） |

| `analyze.html` | 分析（结果：树图 + 列表） |

`design/tidy-redesign/CONTENT.md`（应用真实页面的内容清单）。

## 文件结构

```
design/tidy-redesign/
  index.html          画布：每个页面 × 方案 A/B × 1320/800 并排对比（iframe）
  BRIEF.md            本文件
  CONTENT.md          页面内容清单
  a/a.css             方案 A 样式（tokens + 组件 + 断点）
  a/*.html            方案 A 的 8 个页面
  b/b.css             方案 B 样式
  b/*.html            方案 B 的 8 个页面
```

每个页面是独立 HTML，整页就是应用窗口内容（报头 + 主体），不画 macOS 窗口外壳；
页面直接用浏览器打开、拖动宽度就能测试自适应。
