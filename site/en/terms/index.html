Current release status

The current version is 0.1.0. The installer is signed with a Developer ID (team HQ537XMLJY) and notarized by Apple.

There is exactly one official channel: github.com/rambocode/tidy/releases. A Tidy installer obtained anywhere else was not distributed by this project — do not run it. This is a tool that deletes files, so a copy of unknown origin carries real risk. You can verify the signing team yourself with codesign -dv --verbose=4 /Applications/Tidy.app and check it reads HQ537XMLJY.
